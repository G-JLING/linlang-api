# 琳琅-开发者接口

琳琅（linlang）是一个用于简化 Minecraft（模组、插件）开发的开发库，由 JLING 编写，计划长期维护。

> 此项目正在开发过程中

## 项目结构
琳琅分为两个部分：开发者接口和运行时。其中，开发者接口是面向所有想要使用 linlang 开发插件或模组的开发者的；而运行时仓库则发布 java 程序包，运行在游戏或服务端中，为 linlang 接口提供具体实现。
